# Bibliometrix Analysis – Class Practice

## Visuals
1. **01-annual-production.png**  
   This bibliometric analysis analyzes scholarly research done on digital media and social media studies, with an emphasis on women in Canada. The dataset was examined using Bibliometrix which identified key sources and trends found within this field in 2025 & the beginning of 2026. 

2. **02-most-relevant-sources.png**  
   This shows the highest publishing journals in the dataset. "Jurnal Komunikasi-Malaysian Journal of Communication", "Media and Communication", and "Journal of Behavioral Addictions" are the three most relevant sources.

3. **03-keywords-network.png**  
   This co-occurrence network map shows the relationships between keywords used. "Social media" is shown as the most connect term. The grouping of keywords shows multiple topics within this field are connected.
